# Ehtisham Rehmat - Portfolio

A modern, responsive portfolio built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Features

- ⚡ Next.js 14 with App Router
- 🎨 Tailwind CSS for styling
- 🎭 Framer Motion for animations
- 📱 Fully responsive (mobile-first)
- 🎯 TypeScript for type safety
- ♿ Accessible UI components
- 🎨 Modern gradient designs
- 🚀 Optimized performance

## 📦 Installation
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## 📁 Project Structure
```
src/
├── app/                    # Next.js app directory
├── components/
│   ├── layout/            # Layout components
│   ├── sections/          # Page sections
│   └── ui/                # Reusable UI components
├── lib/
│   ├── constants.ts       # Static data
│   ├── types.ts           # TypeScript types
│   └── animations.ts      # Animation variants
├── hooks/                 # Custom React hooks
└── utils/                 # Utility functions
```

## 🎨 Customization

1. Update personal information in `lib/constants.ts`
2. Modify colors in `tailwind.config.ts`
3. Add/remove sections in `app/page.tsx`
4. Customize animations in `lib/animations.ts`
